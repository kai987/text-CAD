# R05 外构与基础参数记录

本次增加地基、围栏和紧凑院子。未收到特定院子布局时，采用南侧入口步道、一个停车位、少量绿地及围栏开口。全部尺寸为**演示假设**，实际地块、道路、地质和施工构造尚未确定。确认的房屋与阁楼几何及既有平面图保持。

## 命名与修改

参数源 `src/lib/site_geometry.py` 的冻结数据类 `SiteParameters` 及派生 `site_dimensions`、`fence_layout` 被三维模型和补充图共同读取。修改参数后再生成 STEP / GLB 和补充 DXF / PDF。

| 顶层分组 | 子分类 |
| --- | --- |
| foundation | raft / stem_walls / entrance_supports |
| yard | soil / ground_surfaces / entrance_path / parking / planting |
| fence | posts / panels / footings |

新增113个叶实体，原424个房屋与阁楼叶实体保留，共537个。围栏横桟与两侧竖框融合为单一面板实体，中间保留实际空隙；南侧开口不放置透明或占位面板。土层避开房屋、入口和柱脚，面层避开围栏柱，实体边界相接而无多余实心重叠。

网页的完整外观预设显示外构；1层、2层和阁楼内部预设隐藏它。可用分组的“单独”按钮查看地下基础。查看器通过真实1层楼板的上表面锚定完成面，而非整个模型最低点，因此新增Z=-950的柱脚不会移动既有剖切高度。中文、日语、英文名称与说明同时提供，语言和主题切换保留当前状态。

## 输出与范围

- `STEP/house_3d.step` / `GLB/house_3d.glb`：R05-3D，具名基础、院子和围栏。
- `DXF/house_site_plan.dxf`：可编辑TEXT与DIMENSION，毫米模型空间；A3纸空间视口锁定1:100。
- `output/pdf/house_site_plan_R05_JP.pdf`：A3白底黑色补充图，配置图1:100、明确标示的概念基座断面1:25及入口标高关系。
- `output/review/house_3d_assumptions_R01.json`：当前版本R05-3D，含 `site` 参数、面积和8项新增假设。保留原文件名兼容下载。
- `checks/validate_site.py`：保存后的实体、层级、开口、接触、无多余互穿，以及可编辑补充图的核对。

这是空间展示方案，未进行配筋、承载、抗震、地盘处理、排水、道路接入、边界测量或施工设计。原有确认的R02两层图纸及R04阁楼补充图不重写。

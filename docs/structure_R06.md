# R06 木造承重候选方案与待核定事项

用户已明确这是**演示方案**，用途目标为“两层住宅＋纯储物阁楼”。未提供建房所在地、真实地块、道路、地盘调查、材料等级或储物重量。R06增加的是可分组查看和修改的结构候选模型及补充图，**未完成结构计算、承载评定、法规认定或施工设计**。

## 模型与尺寸

已确认的两层平面、房间、门窗及主楼梯位置保持。外轮廓7280×7280 mm、两层层高2800 mm继续作为演示假设。阁楼完成面Z5618、1200×650检修口、既有屋顶外形保持；R06阁楼内部采用最高净高1350 mm的固定天花候选处理，所在地是否接受该处理、面积认定及其他用途条件仍待当地确认。

## 候选传力与空间关系

候选路径为：屋顶面及阁楼板 → 垂木、母屋、棟梁、根太与梁 → 柱及候选墙 → 土台 → 内部基础肋、外圈基础及底板 → 地盘。模型接触检查只确认几何路径，没有计算传力大小、构件能力或连接能力。

33个柱位在一、二层闭合墙段内对齐；另1个仅一层柱C34位于LDK侧既有墙中，为横向梁提供候选支点。未将二层卧室分隔线向一层强行延伸。梁位于门窗上方，主楼梯空间和检修口保持开放。候选墙面跨到柱面与梁面，代表连接位置；墙倍率、钉距、接合细节及力学连接均未指定。

内部基础支持线`I01`～`I05`由`foundation_support_segments(p)`统一派生：

| ID | 轴线与范围（mm） |
| --- | --- |
| I01 | Y3360，X90～7190，LDK上部横向支持线 |
| I02 | Y4330，X90～7190，南北房间分界支持线 |
| I03 | X5150，Y90～7190，LDK与入口核心侧线 |
| I04 | Y1530，X6150～7190，厕所南侧支持线 |
| I05 | X6150，Y1530～3360，厕所西侧支持线 |

根太、梁和屋架均有独立稳定名称。土台角部、梁交叉部采用几何接合；它们是显示协调方式，不是已设计的榫、金物、螺栓、柱脚锚栓或抗拔连接。

建筑墙、楼板、屋顶仍保留为外观展示壳；这些壳与可选木造结构层存在**有意的模型叠置**。查看“结构方案”预设时隐藏外观壳后观察木构与基础，不能把叠置壳同时视为另一套承担荷载的构件。原一层200 mm楼板壳仍不是已设计的木楼面或混凝土承重板；首层楼面层次、通风与防潮构造留待正式设计。

## 需要计算和输入

`src/lib/engineering_inputs.py`及生成的`output/review/engineering_inputs_R06.json`保留未填写项。所在地、测量与道路、用途地域和防火分区、地盘支持力与沉降、雪及风条件、木材材种与等级、面材与连接件、混凝土和钢筋等级、恒载及住宅/储物活载均为`null`。承载结果与法规合规结果也为`null`。

必须完成的计算包括恒载、使用及局部储物荷载，雪、风与地震组合，墙量和墙体分布/偏心，楼面与屋面水平构面，梁及根太弯曲/剪切/挠度/振动，柱稳定，洞口边梁反力，金物、锚栓与抗拔连接，基础反力、地盘承载、沉降和配筋。**阁楼可能不计法规面积，不等于储物荷载不计入结构设计。**

重点未解决事项：

- LDK及棟梁存在长跨度；当前梁高与柱截面没有强度或变形结果，不得作为施工截面。
- 检修口将部分根太荷载转给边框，需要计算边框、支承及连接；梯子产品、展开净空和防坠构造仍待确定。
- 150厚底板、140宽立墙和内部支持肋仅是空间示意。不能从柱脚接触推断地基能力，未设计钢筋和地盘处理。
- 当前墙面标记没有认定墙倍率，不能据此声称达到所需墙量、耐震等级或抗风能力。
- 1350净高是本演示的几何目标；未选定适用自治体，不代表自动获准面积/层数不算入。

正式工程应由具备相应资格的日本建筑士按实际所在地和输入完成结构设计、当地用途认定、确认申请及施工监理。参考官方入口：[国土交通省木造基准说明](https://www.mlit.go.jp/jutakukentiku/build/jutakukentiku_house_tk_000166.html)、[国土交通省确认审查说明](https://www.shoenehou-online.mlit.go.jp/faq/standards/)。本补充图不替代这些过程。

## 输出与核对

- `STEP/house_3d.step`与`GLB/house_3d.glb`：结构、阁楼及基础具名分组。
- `DXF/house_structural_scheme.dxf`：两张A3纸空间，模型毫米单位；TEXT、MTEXT和DIMENSION可编辑。构件标号采用2 mm纸面字高、尺寸采用2.5 mm字高，标号避让并使用适应画布的背景遮罩。第1张为两层柱梁/候选墙1:50，第2张为基础支持线、阁楼床组及东/西参考断面1:75，明确标示的基础参考断面1:25。
- `output/pdf/house_structural_scheme_R06_JP.pdf`：相同内容的两页A3黑白补充图。
- `checks/validate_structure.py`：从保存后的STEP/GLB检查名称、实体、柱墙位置、洞口、框架接触、基础与土台接触、候选面端柱关系、可编辑尺寸及未填写工程输入；`--source`只核对轻量原生参数几何。

这些核对检查几何、标注和记录一致性，**没有执行结构计算或法定审查**。一、二层原平面图继续作为已确认空间布局；不能因为补充结构模型通过几何检查，就把原平面图改称确认申请或施工图。

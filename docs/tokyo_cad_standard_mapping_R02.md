# R02 住宅平面図と東京都 CAD 製図基準の対応

対象：日本二階建て一戸建ての一階・二階平面案。外形 7,280 × 7,280 mm、階高 2,800 mm はユーザー指定の**演示仮定**であり、実測値や法定値ではない。承認済みの間取り、開口位置、階段位置及び寸法は R01 のまま保持し、R02 は図面表現を改訂する。

出典：[東京都建設局 CAD 製図基準（令和6年4月、土木202404-01）](https://www.kensetsu.metro.tokyo.lg.jp/documents/d/kensetsu/000067788)。保存資料は `references/tokyo_cad_drafting_standard_000067788.pdf` と、その抽出本文 `.txt`。以下のページ番号は文書に印刷された番号であり、PDF 閲覧ソフトのページ番号とは異なる。

## 適用範囲

同基準の 1-1（p.1）は土木設計業務の成果図、土木工事の発注図・完成図を対象とする。住宅建築は 1-2（p.2）の対象34工種に含まれないため、今回の住宅案では、同頁の「該当しない工種は類似工種の名称・レイヤ構成を参考とする」という取扱いに基づき、総則の共通製図項目を**住宅へ準用**する。東京都の住宅確認申請仕様、建築意匠図の全要件、JIS 本文の全項目の認証を意味しない。

## 共通項目の対応

| 基準の節・印刷頁 | 規定・趣旨 | R02 に実装する内容・適用判断 |
| --- | --- | --- |
| 1-3, p.3 | 図面レイアウト、表題欄と図形情報の重なりを避ける | 建物平面を左側、面積・仮定注記を右側、表題欄を右下に配置。モデル空間と紙空間を分離。 |
| 1-4-1, p.4 | A1を標準とし、適切な場合はA列サイズから選択 | 既にユーザーが確認した **A3横 420 × 297 mm** を維持する住宅案への適用判断。A1標準を省略せず、A列の代替選択として明示。 |
| 1-4-3, p.6 | A3輪郭線は実線0.7 mm、余白7.5 mm | 四辺7.5 mm。輪郭の紙座標は (7.5,7.5)～(412.5,289.5)。綴じ代追加は今回の非製本の検討図には適用しない。 |
| 1-4-4, pp.7–8 | 表題欄は右下の輪郭に接し、8項目、和暦。項目の変更・追加可 | 図1-3のA3寸法 **60 × 45 mm** を使用。住宅向けに路線名欄を施設名へ読み替え、施設名、工事件名、工事箇所、図面名称、縮尺、図面番号／総数、作製年月日、事業所名を記載。作製日は **令和8年10月4日**。実際の所在地・発注者が未定のため未定と記載。 |
| 1-4-5, p.9 | 尺度は紙出力の図形と実物の割合 | 紙出力 **1:50**、モデル空間 **mm・実寸1:1**。紙空間 `JP_A3_1_50` に固定縮尺ビューポートを設ける。これは本住宅案の尺度選択であり、土木34工種の固有尺度を住宅へ強制したものではない。 |
| 1-5-2, pp.11–12 | 通し番号、ライフサイクル、整理番号、図種、改定履歴、ユーザー領域による命名 | `001D0PL2-1FPLAN.DXF`、`002D0PL2-2FPLAN.DXF`。001／002=図面通し番号、D=設計、0=整理番号、PL=平面図、2=R02、末尾=階別。DXF拡張子への準用であり、規定されるP21／P2Zの納品条件とは区別する。 |
| 1-5-6, pp.17–18 | レイヤは責任主体／図面オブジェクト／作図要素／任意ユーザー領域。追加要素は略語と概要を記録 | D=設計、STR=主構造物、BYP=副構造物、BMK=基準、TTL=図枠、DOC=文章を使用。下表で住宅用の追加作図要素を記録。XMLの図面管理項目は今回未作成。 |
| 1-5-7, pp.19–20 | TTL、BMK、STR等の図面オブジェクトの意味 | 図枠と注記を住宅平面の主要図形から分離。背景地形、実測測量、公共座標は未取得のため作成しない。 |
| 1-5-8, p.21 | 原則16色。黒背景画面を考慮した色例と紙出力への変更可 | 全レイヤ **ACI 7**、実体は **ByLayer** を基本とし、固定RGBを付けない。黒背景では白、白背景／印刷では黒となるCADの表示方式を採用。白・黒は規定色であるが、ACIの背景追従はDXF側の実装。 |
| 1-5-9, pp.22–24 | 指定線種・線幅群。寸法線0.13 mm、A3輪郭0.7 mm。細・太・極太の組合せ | 平面の可視線は実線。住宅案の本体を0.13／0.25／0.50 mm群で表現。寸法線0.13 mm、図枠0.70 mm。紙出力での線幅を設定し、ビューアのズーム画面の見え方と区別する。 |
| 1-5-10, p.25 | 字高1.8／2.5／3.5／5／7／10／14／20 mm、機種依存文字を避ける | A3紙面の室名3.5 mm、面積・寸法2.5 mm、小注記・家具・門番号1.8又は2.5 mm、タイトル5 mm。モデル字高は紙字高×50。面積は `m2` 等の文字列とし、機種依存の `㎡` を使用しない。日本語はアウトラインフォントを使用。 |
| 1-5-11, p.26 | 寸法機能を使用し、寸法値と対象を正確に渡す | 寸法をネイティブ `DIMENSION` として保持し、測定値はmmの実寸、`DIMLFAC=1`。編集可能なTEXT／MTEXTを使用し、文字をラスタ化しない。寸法値の実寸確認は保存済みDXFを読み直して行う。 |

## 住宅に準用したレイヤ略語・概要

追加要素は以下の住宅用の意味で定義する。土木34工種の付属資料2に住宅用の同一名称が既定されているとは主張しない。既定図面オブジェクトの下で第三階層の作図要素を追加している。

| レイヤ名 | 作図要素略語・概要 | 紙線幅 |
| --- | --- | --- |
| `D-STR-WALL` | WALL：承認済み住宅の外壁・間仕切りの平面境界 | 0.50 mm |
| `D-STR-DOOR` | DOOR：建具の扉、引戸、開き方向 | 0.25 mm |
| `D-STR-WIND` | WIND：窓の平面表示 | 0.25 mm |
| `D-STR-STAI` | STAI：階段の踏板、踊場、昇降矢印 | 0.13 mm |
| `D-BYP-FIXT` | FIXT：家具、衛生器具、収納等の寸法占位 | 0.13 mm |
| `D-STR-TXT` | TXT：室名、面積、主要注記 | 0.13 mm |
| `D-STR-DIM` | DIM：寸法と補助線 | 0.13 mm |
| `D-BMK-NORT` | NORT：仮定の北方向の記号。文字注記は `D-STR-TXT` に配置 | 0.13 mm |
| `D-TTL-FRAM` | FRAM：A3外輪郭 | 0.70 mm |
| `D-TTL-LINE` | LINE：住宅表題欄の外枠・内部区画 | 0.13 mm |
| `D-TTL-TXT` | TXT：表題欄の項目と値 | 0.13 mm |
| `D-TTL-VPRT` | VPRT：紙空間の表示用ビューポート。非印刷、縮尺固定 | 非印刷 |
| `D-DOC-TXT` | TXT：紙空間の注記、面積表、仮定の説明 | 0.13 mm |

全レイヤを実線・ACI 7とする。線幅はレイヤで管理し、ネイティブ寸法ブロックの補助実体では寸法スタイルに同じ線幅を明示する場合がある。DXF内部の既定レイヤ `0` と `Defpoints` はCADの管理用である。ezdxfの既定矢印部品内部にはByBlock（ACI 0）の形状があり、ACI 7の挿入実体の色を継承する。これは固定RGBや別の可視色の指定ではない。

## 保存物と検証の範囲

- 正式名のDXFと従来名 `house_1f_plan.dxf`／`house_2f_plan.dxf` は同一バイト列として保存し、既存ビューアリンクでも新しい内容を開ける。
- DXFの `JP_A3_1_50` レイアウトと `output/pdf/house_floor_plans_R02_JP.pdf` に図枠・表題欄を保持する。text-to-cadのDXFブラウザビューアはモデル空間を表示するため、このビューア画面に紙空間の図枠が表示されない場合は仕様上の差である。
- `checks/validate_jp_drafting.py` が保存されたDXFとPDFの単位、字高、色、線幅、レイヤ名、寸法値、紙幅、図枠、表題欄、ビューポート縮尺と正式ファイル名を検証し、`output/review/validation_jp_drafting.json` に結果を保存する。承認済み間取りの幾何検証は既存の `checks/validate_plans.py` で別に行う。
- 1-5-1（p.10）の **SXF(P21/P2Z)** は今回出力していない。付属資料4の **DRAWING.XML**、電子納品フォルダ一式、SXF対応CADによる納品チェックは未作成／未検証。DXFをP21へ拡張子変更してもSXFにはならない。
- 既存の三次元 **STEP** はCADソリッドの交換形式であり、この基準の二次元図面用 **SXF(P21)** と同一ではない。GLBも電子納品対象図面形式ではない。
- 本検証は共通製図項目の適用結果を扱い、確認申請、設計者の署名、構造・耐震、防火、採光換気、実際の北・敷地・道路、施工納まり、SXF電子納品の全項目適合を証明しない。

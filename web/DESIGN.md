# 查看页设计约束

参考：[完整主界面概念](design/viewer-concept.png)，由内置 Image Gen 基于已保存的 CAD 外观图生成。

这是紧凑的模型查看工具：64px 白色页头、280px 白色控制栏、76px 主工具栏和浅蓝灰模型画布。没有营销区块。强调色 `#274d70`，正文深灰蓝，边框 `#dce2e7`，画布 `#f2f4f7`。CJK 系统无衬线字体；标题20px、栏标题17px、主要操作15px、说明12–14px。按钮4px圆角、1px细边框；预设选中时深蓝底白字。图标用于视角、缩放、下载和部件树操作，并提供文字标签。

主界面文案与概念相同：text-CAD、三维模型、一层平面、二层平面、文件下载、GitHub；模型视图、完整外观、一层内部、二层内部；部件显示、一层、二层、楼梯、屋顶；剖切、剖切高度；方案参数、单位、毫米、外轮廓、层高、尺寸为演示假设、结构与管线尚未建模；日本两层一户建、俯视、重置视角、拖动旋转、滚轮缩放、下载 GLB。

功能所需的其他状态：模型加载/浏览器不支持、全部隐藏时的提示、两层图纸的缩放/净面积/下载、CAD文件列表和假设说明。概念中的模型仅作为构图参考；线上几何和材质始终从原始 GLB 读取。图纸使用原始 R02 A3 PDF 转换的矢量 SVG 预览，并保留 PDF 下载。

移动布局保留同一套颜色、字体和组件：页头导航换至第二行，画布优先，部件树排在画布下方，常用预设横排在画布上方。各控制有键盘焦点与文字标签。

## 已批准的查看体验优化

按用户接受的前三项建议调整：预设移至模型工具栏下方，桌面和窄窗口均可在画布上方操作；左栏改为可展开部件树，保留原模型层级，新增分类显示、高亮和单独查看。高亮采用临时金色材质，清除选择或恢复预设后归还原材质；点选显示具体 CAD 原名，拖动旋转不触发选择。侧栏高亮保留已有分类筛选与相机角度，单独查看才重新适配视角。

平面使用原 R02 PDF 转换的字形轮廓 SVG，默认只看平面，提供完整图框切换，按容器宽高适配；裁切不省略两向总尺寸、房间名、门弧及北向箭头。新增工具沿用原按钮、字体、深蓝选中状态和白色图纸背景。其他配色与容器形式继续复用原设计，辅助文案加深以改善阅读。
